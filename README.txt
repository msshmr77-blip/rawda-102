موقع روضة ١٠٢ - حائط رسائل مشترك

الملفات جاهزة للرفع على GitHub ثم Vercel.
لجعل الرسائل مشتركة بين الجميع نحتاج ربط Supabase.

SQL المطلوب في Supabase:
create table messages (id bigint generated by default as identity primary key, name text not null, message text not null, created_at timestamptz default now());
alter table messages enable row level security;
create policy "public read messages" on messages for select to anon using (true);
create policy "public insert messages" on messages for insert to anon with check (true);

ثم ضعي Project URL و anon key في app.js. لا تضعي Service Role Key.
